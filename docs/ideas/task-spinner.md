# Idea card

**Captured:** 2026-10-29

My assistant and I use a dashboard during the day which includes a spinner and something that reads my task fields, adds her notes, offers rescheduling, and so on. We should just build the spinner into Nextcloud, with filters for area, days, and the like. Then I would work out of Nextcloud with the built-in tasks manager. And there is a delivery tracker, which I suppose could be a spreadsheet.

**Replaces or competes with:** the day dashboard I use now (a separate page with the spinner, task notes and rescheduling).
