# 0015. Phone browser, not a native app

- Status: accepted
- Date: 2026-10-23
- Grilling decisions: 24

## Context
Phone CalDAV clients already show the same tasks and order.

## Decision
The panel is responsive in Nextcloud's mobile web view, with long-press to drag on touch. No native app.

## Consequences
Drag handling must work with both mouse and touch.
